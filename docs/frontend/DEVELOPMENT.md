# Frontend development

The standalone React/Vite application lives in `src/frontend`. It does not need Replit's package catalogue or Node server. Use Node **24.19.0** (`.node-version`) and pnpm **11.25.0** (`packageManager`).

From the repository root:

```powershell
pnpm --dir src/frontend install --frozen-lockfile
pnpm --dir src/frontend dev
```

Open the URL Vite prints. Development `/api` requests proxy to `http://127.0.0.1:8000`. Run the normal backend separately using the team's root setup instructions; its database and inference credentials stay on the server. No credentials belong in `VITE_*` variables.

## Modes

**Live is the default.** The application sends real API requests. A failed service request remains an error; it never becomes a prepared success. `VITE_API_BASE_URL` optionally selects an approved API origin. A separate API origin needs server CORS support; the existing development proxy avoids that requirement. Prefer one origin in deployment.

To run the explicitly prepared preview in PowerShell:

```powershell
$env:VITE_API_MODE = 'preview'
pnpm --dir src/frontend dev
```

Restart Vite after changing configuration. Remove that variable to return to the backend:

```powershell
Remove-Item Env:VITE_API_MODE -ErrorAction SilentlyContinue
pnpm --dir src/frontend dev
```

Preview is a tab-local simulation, visibly labelled. It uses fixed **22 October 2026** examples generated by the production Python rules. It calls no model and saves no database records. Only its exact prepared photo/material pairs and prepared renewal payloads work. Other input explicitly requires the backend. The picker provides **Reset prepared examples**. Reloading also resets business examples; sessionStorage remembers only a validated role/organisation. Preview counts are not evaluation measurements.

## Routes and workspaces

| Route | Purpose |
| --- | --- |
| `/` | Project introduction for judges/new visitors |
| `/demo` | Role and organisation picker; preview reset |
| `/check` | Staff material search, original photo upload, saved coverage/checklist result |
| `/review` | Supervisor queue, evidence comparison, decision and required reason |
| `/masterlist` | Staff/supervisor's own SME materials, search and coverage filters |
| `/activity` | Supervisor's own SME activity and decision reasons |
| `/certificates` | Supplier's own current/previous certificates and structured renewal |

Staff and supervisors can select Sunrise Bakery SAMPLE or Crescent Caterer SAMPLE. Suppliers select Golden Grain Supplies SAMPLE (1) or Silver Valley Ingredients SAMPLE (2). Navigation and queries enforce those role boundaries. Demo headers simulate identity; they are not production authentication.

## Checks and output

```powershell
pnpm --dir src/frontend test --run
pnpm --dir src/frontend lint
pnpm --dir src/frontend build
uv run pytest tests/frontend -q
```

Build output is `src/frontend/dist/public`. Serve its assets and `index.html` using a web host with SPA fallback for the routes above, and proxy `/api` to FastAPI. FastAPI currently does not mount this SPA. Vite's development proxy does not exist in the production build. The backend/deployment owner must configure the host before publishing.

After seed, rule, schema or prepared-photo changes, regenerate and review fixtures:

```powershell
uv run python tests/frontend/generate_preview.py
uv run pytest tests/frontend -q
pnpm --dir src/frontend test --run
```

Photographs are fictional SAMPLE assets and live only in `src/frontend/public/media/`. Full-resolution progressive JPEGs reduce download size; their EXIF descriptions identify them as AI-generated derivatives and retain the source PNG SHA-256. Preview hashes match the shipping JPEG bytes. Original PNGs, duplicate source plates, prompts, intermediate mockups and design-tool files are archived locally outside the repository. The implemented design tokens are in `src/frontend/src/styles/`; final review reports and application screenshots are in `docs/frontend/reviews/2026-10-23/`.
